## 🚀 How to Install

1. Install a user script manager like [Tampermonkey](https://www.tampermonkey.net/) (Chrome/Edge/Safari) or [Violentmonkey](https://violentmonkey.github.io/) (Firefox).
2. Click the **📦 Install** link next to the script you want in the table above.
3. Your extension will open a new tab. Click **Install** or **Confirm**.
4. The script will automatically update in the background whenever I push a new version here.
